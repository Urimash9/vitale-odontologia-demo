# Vitale Odontologia — Demo AVERO

Projeto independente da Vitale Odontologia / Dra. Amanda Neves Barbosa.

## Base de referência

A arquitetura e algumas soluções técnicas partem da demo `Urimash9/pires-pena-odonto-demo`, usada somente como referência/matriz técnica. O projeto Pires Pena permanece preservado e independente.

## Direção

Vitale deve ter identidade própria: precisão, naturalidade e cuidado; presença autoral da Dra. Amanda; linguagem off-white, champagne/dourado fosco, madeira, luz e elementos orgânicos inspirados na clínica.

## Fluxo de builds

- `main`: base estável do projeto.
- `build-01-vitale`: primeira adaptação estrutural e visual.

Não fazer alterações no repositório Pires Pena durante o desenvolvimento da Vitale.
